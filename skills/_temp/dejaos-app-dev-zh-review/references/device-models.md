# 设备型号映射快照

## 使用规则

- 快照查询时间：2026-07-30。
- 当前 API 返回 29 个设备型号，映射到 10 个主型号。
- 正式任务必须实时查询；本表只用于人工核对和 API 不一致排查。
- SDK/组件通过主型号查询。
- 默认数据目录按主型号判断：主型号以 `VF` 开头使用 `/data`，其他使用 `/app/data`。
- 子型号不能自动继承主型号的物理 SKU。
