# 设备型号与 SKU 能力

## 决策规则

1. 精确设备型号必须由开发者确认。
2. 标准配置可视为该型号具备。
3. 选配硬件在开发者确认当前设备已安装前按不可用处理。
4. 服务选配在开发者确认部署已开通前按不可用处理。
5. 请求功能不在标准配置或已确认选配中时，不开发。
6. 主型号只用于 SDK/组件查询；子型号不得自动继承主型号 SKU。
7. 硬件能力确认后，仍要验证所选 SDK 的组件列表、`app.dxproj` 和 `dxmodules/`。
8. 本文件未列出的型号标记为“SKU 未内置”，涉及硬件时询问开发者。

## VF105_V12

标准配置：

- Wi-Fi、以太网、韦根
- 一路输出、两路输入
- 扬声器
- 红外补光、白色补光
- 800×1280 屏幕
- 双目摄像头

选配硬件：

- 选配 1：指纹、扫码或无
- 选配 2：测温、4G 或无
- 选配 3：刷卡或无
  - 卡型：单 IC，或 IC+ID
  - VF105 使用非屏下刷卡
  - 屏下刷卡属于 VF205 形态，不能用于推断 VF105
- 选配 4：RS232 或 RS485
- 选配 5：麦克风或无

服务选配：

- 可视对讲
- 云证服务
