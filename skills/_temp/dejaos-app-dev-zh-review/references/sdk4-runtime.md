## 可用性边界

SDK 4.0 的型号覆盖会继续扩大。不要写死支持型号列表。

创建或迁移前：

1. 用精确 `deviceModel` 取得 `mainDeviceModel`。
2. 查询主型号的 SDK 4.0。
3. 查询该 `sdkId` 的最新组件。
4. HTTP 报错、没有 4.0 或组件列表为空时，按当前查询提示该型号不支持 SDK 4.0并停止。

本 Skill 不预制任何型号的组件包装器。SDK 4.0 支持范围必须实时查询，具体 API 必须检查目标项目安装后生成的 `dxmodules/`。

## 架构变化

SDK 3.x 及以前通过多个隔离 QuickJS Worker 和 `dxEventBus` 模拟并发：

```text
Worker A <-> dxEventBus <-> Worker B
```

它带来多份运行时内存、跨 Worker 消息样板、额外延迟、状态同步和排错复杂度。

SDK 4.0 改为：

```text
一个 JS 运行时
  + 一个集中调度的事件循环
  + 原生线程执行阻塞或重任务
```

SDK 4.0 App 不得创建 Worker。`dxStd` 已移除 Worker 能力；即使某个安装结果或兼容组件列表中仍存在 `dxEventBus.js`，也不能把它的 Worker 路径作为 4.0 App 架构。

## 调度模型

典型流程：

```text
JS 调用组件包装器
  -> 原生线程执行任务
  -> JS 事件循环继续运行
  -> 结果进入原生队列
  -> pipe 唤醒 JS
  -> 组件内部通过 dxSystemBus 接收
  -> Promise resolve/reject 或组件事件触发
```

App 使用组件公开的 Promise 和事件 API，不复制原生队列或任务路由。

## App 结构

- `src/main.js` 是组合入口，负责配置、依赖组装、启动和顶层失败处理。
- 使用普通模块、服务、控制器、领域对象和驱动适配器划分职责。
- 需要返回结果的操作使用直接异步函数调用。
- 真正的通知或广播才使用 App 自己的事件发射器。
- 不用 `dxSystemBus` 充当业务事件总线。
- 事件回调保持短小；从回调启动的异步工作必须捕获拒绝。
- 不在 JS 事件循环中执行同步休眠、长循环、重计算或可避免的同步 I/O。

“单运行时”不等于把整个应用写进一个文件。

## dxSystemBus 边界

- SDK 4.0 项目必须安装 `dxSystemBus`。
- HTTP、MQTT、SQLite、人脸、网络、NFC 等组件包装器可能在内部 import 它。
- 普通 App 业务代码不 import、不订阅、不直接调用 `dxSystemBus`。
- 只有开发组件包装器时，才用它把原生完成事件转换为公开 Promise 或组件事件。

## 生命周期

推荐模块暴露：

```text
init -> start -> stop -> destroy/deinit
```

规则：

- 按依赖顺序初始化。
- 记录已经成功初始化的步骤。
- 启动部分失败时回滚已完成步骤。
- 按相反顺序停止和销毁。
- 取消事件监听器和定时器。
- 关闭 MQTT/HTTP 客户端、数据库和原生组件。
- 多实例客户端使用唯一 `sourceId`。
- 根据已安装包装器验证 source ID 字符和长度限制。

## 从旧版本迁移

1. 盘点 Worker、EventBus topic、RPC、轮询循环和组件所有权。
2. 把有返回值的 Worker RPC 改为直接异步服务调用。
3. 只有广播语义仍成立时才保留为 App 事件。
4. 把组件轮询改为 4.0 包装器公开的 Promise 或 `on/off/once`。
5. 使用包装器异步 API，不用高频定时器模拟异步。
6. 合并初始化流程并实现部分失败回滚。
7. 删除 Worker 间重复的配置、状态和日志。
8. 对照 4.0 项目 `dxmodules` 重新检查所有函数、返回类型和事件。
9. 替代方案真机验证前，不删除仍在工作的兼容路径。

## 审查清单

- 是否存在 Worker、`newWorker` 或 4.0 中不可用的 Worker API？
- 是否遗漏 `await` 或 Promise 拒绝处理？
- 是否在事件循环执行同步阻塞工作？
- App 是否直接使用 `dxSystemBus`？
- 客户端 `sourceId` 是否重复？
- 初始化和逆序销毁是否完整？
- 监听器、定时器和客户端是否泄漏？
- 是否使用项目包装器不存在的事件或函数？
- 是否根据错误型号/SKU 开发硬件功能？
- 是否未经 USB 运行和日志就声称真机验证通过？
